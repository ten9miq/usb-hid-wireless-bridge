# WBT2-V4 互換性検証

## 記録する入力

| 入力 | 直結 PC | WBT2-V4 経由 | 備考 |
|---|---|---|---|
| 英数キー / 修飾キー | 未実施 | 未実施 | Usage の -4 ずれを記録 |
| 6 キー以内の同時押し | 未実施 | 未実施 | 6KRO A/B |
| 7 キー以上の同時押し | 未実施 | 未実施 | rollover の境界 |
| マウス移動 X/Y | 未実施 | 未実施 | 相対 8-bit 想定 |
| 左右ボタン | 未実施 | 未実施 | |
| Wheel | 未実施 | 未実施 | |

## 判定

「直結 PC で成功」だけではブリッジ互換性の証拠になりません。WBT2-V4 経由で同じテストを行い、descriptor 解釈差を分離します。
